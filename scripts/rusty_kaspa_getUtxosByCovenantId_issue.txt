### Summary

Toccata covenants are live on mainnet and TN10. Integrators need UTXOs locked under a `covenant_id` without scanning all deposit addresses. kaspad exposes `getUtxosByAddresses` but not covenant-scoped lookup.

Community indexers (e.g. [kascov](https://kascov.io/)) fill the gap today. A native RPC would help wallets, exchanges, and covenant apps use the node's UTXO set as source of truth.

### Proposed RPC

```json
{
  "method": "getUtxosByCovenantId",
  "params": {
    "covenantId": "<32-byte hex>",
    "includeMempool": false
  }
}
```

Response shape mirrors `getUtxosByAddresses` entries. Return an error when `--utxoindex` is disabled — do not silently proxy third-party indexers from kaspad.

### Semantics

- Source of truth: node UTXO set with `--utxoindex` (same prerequisite as address lookup)
- Optional mempool inclusion (default false for custody integrations)
- Pagination (`limit` / cursor) for large covenant UTXO sets on TN10
- Explicit `verified` semantics when the node cannot attest rows

### Non-goals

- Not a replacement for kascov lineage/history APIs
- Not token metadata (KCC-0020 is separate)
- Not a shortcut to skip `--utxoindex` on exchanges
